Guía rápida de CartelGo. Todo se organiza en cuatro pestañas y los cambios se guardan localmente en el dispositivo.

🎨

1. Pantalla y fondo

En la pestaña Pantalla elige color sólido, degradado o una foto de tu galería. También puedes oscurecer la fotografía y controlar orientación y pantalla activa.

Pantalla → color · degradado · imagen
🔤

2. Configura hasta 3 líneas

En Texto encontrarás Línea 1, 2 y 3 inicialmente recogidas. Abre solo la que necesites; cada una tiene su propia fuente, tamaño, color, contorno, mayúsculas y estilo LED.

Línea 1
Línea 2 (opcional)
Línea 3 (opcional)
✨

3. Combina efectos

Parpadeo, desplazamiento y pulso pueden funcionar a la vez. El desplazamiento puede ir a izquierda o derecha y cada efecto tiene su velocidad.

← scroll + parpadeo ✦ + LED
📱

4. Orientación horizontal

CartelGo intenta cambiar automáticamente a horizontal al mostrar un cartel o una secuencia. Para que este bloqueo sea más fiable, se recomienda instalar la PWA. Si se usa directamente desde el navegador y el sistema no permite el giro automático, bastará con girar el teléfono manualmente.

Instalada → horizontal automático cuando el dispositivo lo permite
📺

5. Muestra el cartel

El botón “Mostrar cartel” está siempre debajo de las cuatro pestañas. CartelGo cubre la zona visible de la PWA sin activar el fullscreen nativo del navegador.

Mostrar cartel → ✕ para volver
💾

6. Guarda tus carteles

En Guardados, pon un nombre y pulsa “Guardar cartel”. También se conserva la imagen de fondo si la configuración la utiliza.

Cargar = editar · Ver = mostrar · Borrar = eliminar
🔁

7. Crea una secuencia

En Guardados marca “Secuencia” en varios carteles y define el tiempo y la repetición. Después usa “Iniciar secuencia”, siempre visible debajo de las pestañas.

Cartel A → Cartel B → Cartel C → repetir
Consejo: para recogidas, nombres largos o aeropuertos suele funcionar muy bien el ajuste automático de tamaño con alto contraste entre texto y fondo.
